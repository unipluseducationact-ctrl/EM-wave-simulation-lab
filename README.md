# EM Wave Simulation Lab

**Electromagnetic Spectrum Explorer (v2)** — an interactive web app for exploring the electromagnetic spectrum. Tune wavelength and frequency, see band labels and photon energy, and try simulation-lab demos (transverse waves, speed in media, wave phenomena, penetration). The UI supports English and Chinese.

## How to run

### Windows

Double-click **`Open EM Spectrum.bat`**. It ensures `em-spectrum.html` is saved as UTF-8 (fixes garbled text if the file was UTF-16) and opens the app in your default browser.

### Any OS

Open **`em-spectrum.html`** in a modern browser (Chrome, Edge, Firefox, Safari). Keep the HTML file in **UTF-8** encoding when editing.

## Files

| File | Description |
|------|-------------|
| `em-spectrum.html` | Main app (HTML, CSS, JavaScript) |
| `i18n-bundle.json` | UI strings (English / Chinese) |
| `Open EM Spectrum.bat` | Windows launcher and UTF-8 helper |

## Requirements

- A modern web browser with JavaScript enabled
- No build step or server required — runs locally from disk
